# 🎒 PackMate – Smart Travel Planner

**Pack Smart, Travel Easy.**

PackMate is a simple and user-friendly travel planning website that helps users organize their trips and manage their packing checklist. It allows users to create travel plans, save trip details, and track their packing progress.

## ✨ Features

- 🏠 **Home Page** – Clean landing page with an introduction to PackMate.
- 🗺️ **Create Trip** – Add trip name, destination, dates, travel type, and additional notes.
- ✅ **Packing Checklist** – Add, remove, and manage packing items.
- 📊 **Packing Progress** – Track packing completion with a progress bar.
- 💾 **My Trips** – View your saved travel plans.
- 🔄 **Local Storage** – Save trips and checklist items directly in the browser.
- 📱 **Responsive Design** – User-friendly layout for different screen sizes.

## 🛠️ Technologies Used

- HTML5 – Website structure
- CSS3 – Styling and responsive design
- JavaScript – Functionality and interactivity
- Local Storage – Saving user data in the browser


## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
4. Start planning your next trip!

## 🎯 Project Objective

The main objective of PackMate is to make travel planning easier by bringing trip organization and packing management together in one place.

This project was developed as a beginner-friendly web development mini project to practice HTML, CSS, and JavaScript.
